Класс для шифрования методом Гронсфельда

Реализует модифицированную версию шифра Гронсфельда для работы с русским алфавитом. Поддерживает операции шифрования и дешифрования с полной валидацией входных данных.

Предупреждения
Класс не имеет конструктора по умолчанию. Требуется указать ключ.
Заметки
Алфавит: "АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ"

Инициализирует алфавитную карту и валидирует ключ.

Аргументы
skeyКлюч шифрования
Исключения
cipher_errorЕсли ключ невалиден

Инициализирует объект шифра:

  1. Создает карту соответствия символов алфавита их индексам
  2. Валидирует ключ с помощью getValidKey()
  3. Преобразует ключ в числовую форму с помощью convert()
