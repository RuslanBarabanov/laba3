Модифицированный шифр Гронсфельда -\/ это полиалфавитный шифр подстановки, работающий с русским алфавитом. Шифр использует ключ для сдвига символов в алфавитной таблице.\hypertarget{index_features_sec}{}\doxysection{Особенности}\label{index_features_sec}

\begin{DoxyItemize}
\item Работает только с русскими буквами
\item Игнорирует неалфавитные символы при шифровании
\item Автоматически преобразует текст в верхний регистр
\item Проверяет ключ на \char`\"{}слабость\char`\"{} (одинаковые символы)
\item Полная валидация входных данных
\end{DoxyItemize}
