Алгоритм дешифрования\+:
\begin{DoxyEnumerate}
\item Валидация количества столбцов и зашифрованного текста
\item Расчет количества строк\+: rows = ceil(длина\+\_\+текста / columns)
\item Проверка корректности длины текста (rows×columns == длина\+\_\+текста)
\item Создание таблицы rows×columns, заполненной пробелами
\item Запись шифротекста в таблицу снизу вверх по столбцам
\item Чтение таблицы построчно для восстановления исходного текста
\end{DoxyEnumerate}

\begin{DoxyNote}{Заметки}
Требование rows×columns == длина\+\_\+текста необходимо потому, что шифротекст должен полностью заполнять таблицу без лишних символов. 
\end{DoxyNote}
