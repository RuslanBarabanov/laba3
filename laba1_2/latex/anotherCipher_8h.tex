\doxysubsection{Подробное описание}
Заголовочный файл для шифра перестановки по столбцам 

Реализация шифра перестановки по столбцам -\/ симметричного блочного шифра, использующего табличную перестановку символов.\hypertarget{anotherCipher_8h_algorithm_sec}{}\doxysubsection{Алгоритм шифрования}\label{anotherCipher_8h_algorithm_sec}
Алгоритм работает по следующей схеме\+:
\begin{DoxyEnumerate}
\item Текст записывается в таблицу построчно с заданным количеством столбцов
\item Пустые ячейки заполняются пробелами
\item Шифротекст формируется чтением таблицы снизу вверх по столбцам
\end{DoxyEnumerate}\hypertarget{anotherCipher_8h_decrypt_sec}{}\doxysubsection{Алгоритм дешифрования}\label{anotherCipher_8h_decrypt_sec}
Для дешифрования используется обратный процесс\+:
\begin{DoxyEnumerate}
\item Шифротекст записывается в таблицу снизу вверх по столбцам
\item Оригинальный текст читается построчно
\end{DoxyEnumerate}

Алгоритм дешифрования\+:
\begin{DoxyEnumerate}
\item Валидация количества столбцов и зашифрованного текста
\item Расчет количества строк\+: rows = ceil(длина\+\_\+текста / columns)
\item Проверка корректности длины текста (rows×columns == длина\+\_\+текста)
\item Создание таблицы rows×columns, заполненной пробелами
\item Запись шифротекста в таблицу снизу вверх по столбцам
\item Чтение таблицы построчно для восстановления исходного текста
\end{DoxyEnumerate}

\begin{DoxyNote}{Заметки}

\end{DoxyNote}
